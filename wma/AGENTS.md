# Agent instructions

Read `README.md`, `RULES.md` and the relevant project documentation before making changes. Inspect the current working tree and preserve unrelated modifications. The code and configuration are authoritative when documentation differs.

For each task, update the relevant documentation when behavior, commands, architecture, design or durable decisions change. Record actionable follow-up in `TASKS.md` and confirmed lasting context in `MEMORY.md`; do not add secrets or speculative claims. Keep entries concise and dated where useful.

Run checks suitable for the change and report results and outstanding risks. Preserve existing database and migration history; consult the deployment notes before running commands that change persistent data.
